# Hub and travel lookups

- Hugging Face: *search* the Hub to find models/datasets/Spaces/papers; get *repo details*
  for a known repo id; browse files with the HF filesystem tool; "who am I logged in as"
  uses the whoami tool.
- Flights: the Kiwi flight search finds and prices flights. It cannot book, cancel or change
  bookings; if the request needs that, no tool can do it.
