# Repo research

Use when the user asks about a *specific public GitHub repository*.

- Conceptual "how does X work in repo Y" questions: prefer a wiki/Q&A tool that answers
  questions about a repository (DeepWiki-style).
- "Show me the table of contents / structure" of a repo's docs: use a wiki *structure* tool;
  to read whole generated pages use a wiki *contents* tool.
- Finding a concrete symbol, file or snippet in the source: prefer a code-search tool over a
  documentation tool (GitMCP-style generic code search).
- Fetching a specific URL inside a repository: use a URL-content fetch tool.

Call one tool first; only search for more tools if nothing listed fits.
