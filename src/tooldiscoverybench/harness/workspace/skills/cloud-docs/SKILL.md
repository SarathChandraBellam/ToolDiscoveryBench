# Cloud docs

- AWS: *search* the docs when you need to find pages; *read* a page when the user gives a
  docs.aws.amazon.com URL or wants a full page; use the regions / regional-availability tools
  for "which regions" questions.
- Microsoft (Azure, .NET, M365, Entra): docs search for concepts, code-sample search for
  code, docs fetch for a full learn.microsoft.com page.
- Cloudflare: the Cloudflare documentation search; there is also a dedicated guide for
  migrating Pages projects to Workers.
- Account-level actions (deploying, changing billing, creating resources) are not
  documentation lookups: if no tool performs the action, say so instead of searching docs.
